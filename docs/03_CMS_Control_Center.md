# 03_Anisekai_CMS_Control_Center_Specification_v1.0

# Overview

The Control Center is the heart of Anisekai.

It should inherit the mature management philosophy of CasRadar while
adapting all business logic to Anime & TCG.

The backend must be modular, scalable, and configurable without code
changes.

------------------------------------------------------------------------

# Dashboard

Display:

-   Website overview
-   Latest published content
-   Pending review queue
-   AI task status
-   RSS/API status
-   Traffic overview
-   User statistics
-   Quick actions

------------------------------------------------------------------------

# Content Management

Support management for:

-   Anime Leaks
-   Episodes
-   TCG
-   Trends
-   News

Functions:

-   Create
-   Edit
-   Delete
-   Draft
-   Preview
-   Publish
-   Archive
-   Schedule
-   Bulk operations

------------------------------------------------------------------------

# Homepage Builder

Administrators can:

-   Drag & Drop Widgets
-   Reorder Widgets
-   Show / Hide Widgets
-   Configure widget content
-   Configure Hero Banner
-   Manage homepage layout

No coding required.

------------------------------------------------------------------------

# Menu Manager

Manage:

-   Header Menu
-   Footer Menu
-   Internal Links
-   External Links
-   Navigation Order

------------------------------------------------------------------------

# Banner Manager

Support:

-   Hero Banner
-   Category Banner
-   Sidebar Banner
-   Promotional Banner

Each banner supports scheduling and expiration.

------------------------------------------------------------------------

-   Search

-   Roles

# Analytics

Dashboard includes:

------------------------------------------------------------------------

# Settings

Configure:

-   Website Information
-   Theme
-   Languages
-   Time Zone
-   Email
-   Security
-   Backup
-   Cache

------------------------------------------------------------------------

# AI Integration

The CMS must connect seamlessly with the AI Engine.

Editors should be able to:

-   Generate Article
-   Rewrite
-   Translate
-   Summarize
-   Generate SEO
-   Generate Image

All AI outputs require manual approval before publication.

------------------------------------------------------------------------

# Modular Requirement

Every CMS module must be independently maintainable.

Future modules (Virtual Pet, Marketplace, Forum, etc.) should be
pluggable without redesigning the backend architecture.
