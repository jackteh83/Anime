# 02_Anisekai_Frontend_UI_UX_Specification_v1.0

# Frontend Design Principle

The frontend should inherit the visual philosophy of CasRadar while
replacing all business content with Anime + TCG.

The homepage is a Dashboard composed of widgets, not a traditional news
list.

No homepage widget from the approved design may be removed.

------------------------------------------------------------------------

# Header

Components:

-   Logo
-   Home
-   Anime Leaks
-   Episodes
-   TCG
-   Trends
-   News
-   Search
-   Dark / Light Mode
-   Login / User Profile

Sticky navigation on desktop and mobile.

------------------------------------------------------------------------

# Homepage Widgets

Keep all approved homepage widgets.

Typical widgets include:

-   Hero Banner
-   Breaking Leaks
-   Episode Hub
-   Countdown
-   Today's Trends
-   TCG Hub
-   Card Reveals
-   Latest News
-   Timeline
-   AI Recommendation
-   User Profile Card

Every widget links to its corresponding page.

# Homepage Builder Compatibility

Frontend widgets must be configurable from the CMS.

Administrators should be able to:

-   Show / Hide widgets
-   Reorder widgets
-   Change banners
-   Edit widget titles
-   Configure featured content

No code changes should be required for these operations.
